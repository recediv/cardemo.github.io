# Forest Track

Racing through an autumn forest.

**[Play](https://recediv.github.io/cardemo.github.io/)**

Controls: WASD / arrow keys to drive, Space to brake, Shift to boost, E for horn, F for headlights and underglow, Q to flip, R to reset, C for camera, M for sound. Select Auto in settings to restore automatic lights.

## Run locally

Requires Node.js 20 or newer.

```sh
npm run dev
```

Open http://localhost:5175.

Build: `npm run build` → `dist`. Updates to `main` are published to GitHub Pages automatically.
